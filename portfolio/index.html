Features

What It Does

Four integrated modules managing the full lifecycle of music operations — from artist onboarding to playlist placement.

⚙

Core Module

Artist roster management and project tracking with full CRUD, search (full-text tsvector), filtering, pagination, and role-based access control.

★

Pass Module

Subscription tier management with Stripe-ready architecture. Fan subscriptions, tier definitions, and subscriber analytics.

▶

Port Module

Digital asset portfolio and distribution placement tracking. Kanban board for placement status, asset metadata management.

⚠

Ops Module

Task management and KPI analytics. ECharts-powered dashboards, performance metrics, and operational reporting.

🔒

Auth & RBAC

JWT authentication with session persistence, role-based access (admin/manager/viewer), protected routes, and secure password hashing with bcrypt.

⚡

Production Hardening

Error boundaries, toast notifications, search debounce, DB-aware health checks, graceful shutdown, response-time monitoring.
